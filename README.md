# Insurance-Claims-and-Policy-Analysis-Dashboard
This interactive Power BI dashboard provides a comprehensive analysis of insurance policies and claim metrics across multiple vehicle types and usage categories over several years (2014–2019). It is designed to help stakeholders in the insurance domain understand key performance indicators (KPIs) such as policy growth, claim behavior, and premium-to-claim ratios for strategic decision-making.

## 📌 Key Features
- Policies Managed: 508K total policies opened by EIC
- Financial Overview:
 - Total Premium Collected: $4B
 - Total Claims Made: $9B
 - Average Premium: $8K
 - Average Claim: $18K
 - Premium to Claim Ratio: 44%

- Top Policy Holders by Vehicle Type:
  - Highest: Motor-cycles (106K policies)
  - Lowest: Trade plates (0 policies)

- Yearly Insights:
  - Filter data by Policy Year (2014–2018)
  - Track yearly variations in premium and claims

- Claim Insights:
  - Claims distribution by vehicle usage (e.g., Ambulance, Farm Use, Car Hires)
  - Gender-based claim behavior (SEX 0 shows highest claim count)

- Visual Highlights:
  - Ribbon Chart: Claim trends over time by usage type
  - Donut Chart: Claims by gender
  - Scatter Plot: Average Premium vs Average Claim comparison
  - Heatmap Table: Usage type-wise performance across years

## 📈 Key Insights for EIC
 - 2016 had the highest claim volume ($2.66B)
 - 2018 showed a 114% Premium to Claim Ratio, indicating improved profitability
 - Agricultural and Ambulance categories demonstrated strong performance
 - SEX 0 segment accounts for 63% of claims, a critical demographic for policy review

## 🛠 Tools & Tech Stack
 - Power BI Desktop
 - DAX for calculated fields and KPIs
 - Custom Visuals for scatter plots, heatmaps, and donut charts
 - Data Relationships and filtering via slicers
